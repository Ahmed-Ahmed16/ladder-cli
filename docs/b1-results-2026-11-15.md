## What changed

* Bash tasks run `bash -o pipefail -c <line>`. `pipe` now exits 5, not 0.
* Every task run and every `ladder gates` run (not `--dry-run`) writes its whole screen output to a log file and ends with one summary line that names the log:
  * `ladder: FAIL <task>, step N of M, exit X; full log: <path>`
  * `ladder: ok <task>, M step(s); full log: <path>`
  * `FAIL step N of M: <command> (exit X); full log: <path>` and `gates: all N passed; full log: <path>`
* Timeout: `LADDER_TIMEOUT=<seconds>` is a per-step limit. The step is killed with its process tree, ladder exits 124, and the line says `timeout after <N>s (exit 124)`. A step that already has an exit code when the timer fires keeps its exit code.
* Log folder: `<temp folder>/ladder/logs/`. On POSIX it must be a real folder owned by the user with no group or other access; a link is refused. Files are created exclusive (`O_EXCL`) and owner-only (0600). The log holds the same text as the screen, after `redact()`.
* Teach text: `src/ladder/skill/SKILL.md`, `README.md`, and the epilog of `ladder --help`. The skill was reinstalled with `ladder install-skill`; the installed copies in `~/.claude/skills/ladder` and `~/.agents/skills/ladder` equal the source.
