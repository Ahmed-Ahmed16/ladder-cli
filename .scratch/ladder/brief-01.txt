<build>
1. Package layout with pyproject.toml (setuptools, src layout, package `ladder`, console script `ladder = ladder.cli:run`), requires-python >= 3.12, ZERO third party dependencies. A module `__main__` so `python -m ladder` also works.
2. Runner seam: one class with `capture(argv) -> str` (raises the ladder error with a plain message on non zero exit, including the program's stderr tail but never anything that looks like a token) and `stream(argv) -> int`. It prints `$ <command>` to the output stream before running. A missing program gives a plain error naming it. Use subprocess with an argv list, never shell=True. On Windows, resolve the program with shutil.which so `gh` and `git` work from PowerShell and Git Bash.
3. CLI entry `main(argv, runner, out, err) -> int`, plus `run()` that builds the real runner and calls sys.exit(main(...)). Parse with argparse. Jobs in this ticket: `help` (and `-h/--help`), `doctor`, `pr comments <n> [--all] [--full]`. Unknown job: one plain line on err, exit 1. Any LadderError: one line `ladder: <message>` on err, exit 1. Any other exception: one line, exit 1, no traceback unless env LADDER_DEBUG=1.
4. `doctor`: checks `git --version`, `gh --version`, `gh auth status` (use exit code only; never print its stdout or stderr), and the running Python version (>= 3.12). One line per check like `ok   git 2.x` / `FAIL gh: not found`. Last line `doctor: all checks passed` or `doctor: N check(s) failed`. Exit 0 only when all pass. The runner needs a way to run a command and get its exit code without raising; add it to the seam (for example `check(argv) -> (code, stdout)`), and keep the gh auth output out of every printed line.
5. `pr comments`: port pr.rs exactly: same GraphQL query string, `gh api graphql -F owner={owner} -F name={repo} -F number=<n> -f query=<query>`, parse_threads, render_threads (unresolved first, sorted by (resolved, path, line) with line None sorting before numbers, `[resolved]` `[outdated]` marks, header `PR #<n>: <open> unresolved of <total> threads`), summary (drop HTML tags, HTML comments, whole nested <details> blocks, remove `**`, first 3 non empty trimmed lines). Wrong PR number error must contain "PR number".
6. README.md: what ladder is (2 sentences), install (`pip install git+https://github.com/Ahmed-Ahmed16/ladder-cli` and `pip install -e .` for local), the 3 commands, how to run tests.
