<ticket_03_gates>
`[gates]` in ladder.toml: `about` optional string, `run` required (string or non empty list of non empty strings, same rules as a task), `ci` optional string path relative to the ladder.toml folder. Any other key: error "<path>: gates: unknown key \"<key>\"". Validate in config (add to parse; keep parse readable) and expose as data on Config.
`ladder gates`: no file or no [gates] -> plain message "no [gates] in ladder.toml", exit 1. Runs each step from the ladder.toml folder, no shell, streamed through the runner; after each step print "PASS step N of M: <line>" or "FAIL step N of M: <line> (exit X)"; stop at first failure; exit code = that step's code; final line "gates: all M passed" on success.
`ladder gates --dry-run`: print each step line numbered, run nothing, exit 0.
CI drift warning: when `ci` is set, read that file as text (missing file -> warning line, not failure). For each step, warn "warning: gate step N not found in <ci>: <line>" when the step's text, after collapsing whitespace, is not a substring of the CI file's text after collapsing whitespace. Warnings print before running, go to err, and never change the exit code. Known positive and negative tests.
Extra args to gates other than --dry-run: plain error.
</ticket_03_gates>
